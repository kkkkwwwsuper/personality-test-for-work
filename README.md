# 求职性格测试 — 使用说明

## 文件

| 文件 | 用途 |
|---|---|
| `index.html` | 测试本体，单文件，双击就能用 |
| `cover_dark.png` | 封面（深色，推荐） |
| `cover_light.png` | 封面（浅色备选） |
| `post.md` | 小红书标题、正文、标签、私信话术 |
| `build_cover.py` | 改封面文字后重新生成的脚本 |

## 一、先自己测一遍

双击 `index.html`，用手机浏览器打开也可以（把文件发到手机）。
测完截图结果页 —— 发笔记时用得上。

## 二、改成你自己的

打开 `index.html`，找到这两处：

```js
const CONFIG = {
  ctaText: "私信「简历」，帮你改",
  ctaNote: "知道方向只是第一步……",
};
```

把 `ctaText` 改成你的引导语。
按钮点击目前是弹窗，要跳转就改最后这段：

```js
$("cta-btn").onclick = () => {
  window.location.href = "https://你的链接";
};
```

## 三、拿到一个链接（三种方式）

### 方式 A：Netlify Drop（最快，1 分钟）

1. 打开 https://app.netlify.com/drop
2. 把整个 `personality-test` 文件夹拖进去
3. 得到 `https://随机名.netlify.app`
4. 手机打开验证

免费，不需要域名。缺点：国内访问速度一般，微信里可能提示"非官方网页"。

### 方式 B：GitHub Pages（稳定，需 GitHub 账号）

1. 新建仓库，上传 `index.html`
2. Settings → Pages → Source 选 `main` / `/root`
3. 链接：`https://你的用户名.github.io/仓库名/`

### 方式 C：国内云（最快最稳，要钱）

腾讯云 COS / 阿里云 OSS 静态网站托管。
需要实名 + 备案域名，成本约 ¥50/年。
**如果要在微信里传播，只有这条稳。**

## 四、⚠️ 小红书不能放链接

这是硬规则，不是建议：

- 笔记正文、评论、简介里放外链 = 导流 = 限流/封号
- 正确路径：评论区扣关键词 → 私信发链接
- 私信发链接也有概率被折叠，准备好备用话术（见 `post.md`）

**这个链接更适合放在**：朋友圈、微信群、知乎、微博、你的简历 PDF 里。
